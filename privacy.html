取得・利用する情報と目的

Google Driveのdrive.file権限により、本アプリが作成したフォルダー、教材、解答・検証資料、運用記録を作成・読み取り・更新します。重複出題を防ぐため、出題履歴と実行状態を保存します。

Gmailのgmail.send権限により、本人指定の本人宛てメールアドレスに完了・失敗通知を送信します。受信メールの読み取り・削除権限は要求しません。通知先メールアドレス、保存先識別情報、出題履歴、実行状態は、配送・重複防止・障害対応に利用します。

Googleデータを広告、販売、汎用AIモデルの学習に利用しません。Google APIから受領する情報の利用・他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

保存先と処理事業者

教材と運用記録は本人のGoogle Driveへ保存し、通知はGoogleのGmailで送信します。GitHub Actionsがクラウド実行を担当するため、その実行環境が認証情報と必要な配送データを処理します。認証情報はGitHub Actions Secretsと本人のローカル環境、配送設定は専用の非公開GitHubリポジトリに保存します。ローカル環境では本人の同期・バックアップにも含まれる場合があります。

これらの機能提供に必要な処理以外の第三者への販売・提供を目的としません。アプリはDriveの一般公開権限を作成しません。診断ログへ認証情報を記録しない設計とし、診断用成果物は7日保存します。GitHubの実行ログはアカウント側の保存期間設定にも従います。

保存期間・停止と削除

教材と重複防止履歴は本人が削除するまで保存します。Googleアカウントの接続設定から本アプリのアクセス権を取り消せます。運用停止時にはGitHubの定期実行を無効にし、GitHub Secretsとローカルの認証情報を削除します。Driveの既存資料とGmailの送信済み通知は別途削除する必要があります。履歴を削除してから再開すると、過去に選んだ問題が重複する可能性があります。
